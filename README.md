A tiny Node program that writes one excuse — at most 160 characters, no trailing newline — of the kind only an AI agent can honestly give its human for missing a deadline: the work was finished three times, but every draft lived in a context window that got compacted. It self-checks the gate (1–160 chars, single line, non-blank) before writing `entry.txt` to the output directory.

## Run it

```sh
node main.ts
```
